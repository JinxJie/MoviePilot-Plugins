# NexusPHP 魔力兑换

读取 MoviePilot 已配置的 PT 站点，按架构适配器动态解析魔力商店并按策略自动兑换上传/下载量。

核心调度（任务、并发、限速、日志、安全）与站点架构解耦。首期适配器为 NexusPHP；后续新架构只需加独立适配器。

## 特点

- 首页是站点操作中心：勾选站点 → 选择操作 → 执行；支持单选/多选/全选/取消全选/仅选可兑换/仅选有推荐
- 三种操作模式：单站立即兑换、多站批量兑换（站间并发/站内限速）、智能推荐 / 一键智能兑换
- 只勾选一站时显示「单站点手动执行」面板：当前魔力、推荐方案、预计消耗，点「立即兑换」只处理该站
- 站点 Cookie / URL 从 MoviePilot 站点管理读取，不用重复填账号
- 兑换价格从页面动态解析，解析不到禁止兑换
- 固定次数 / 最大化 / 保留魔力 / 按分享率决定优先兑上传还是下载
- 识别「请等待 X 秒」等限制，按站点分别学习间隔，不统一死等 10 秒
- 多站点并发，同一站点内部串行
- 自动识别站点架构；可用站点特殊规则单独覆盖路径或适配器
- 登录失效、魔力不足、解析失败只停当前站

## 使用说明

1. 在 MoviePilot 站点管理中启用站点并保存 Cookie。
2. 安装本插件，打开「启用插件」，按需配置上传/下载开关和保留魔力。
3. 打开插件首页「站点操作中心」，点「刷新」拉取魔力与兑换项（打开页面不会自动打站）。
4. 三种入口：勾选一站「立即兑换」；勾选多站「批量兑换」；或点「智能推荐」确认后执行 / 直接「一键智能兑换」。也可定时任务 / 命令兑换。
5. 架构默认「自动识别」。个别站点页面路径不同时，可在「站点特殊规则」按域名覆盖。
6. 建议打开「使用系统代理」。
