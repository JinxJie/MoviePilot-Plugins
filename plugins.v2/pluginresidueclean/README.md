# 插件残留清理

一键清理卸载后的插件残留，让插件重装一路顺畅。

## 功能

- **一键清理残留**：把所有「已卸载但仍有残留」的插件一口气清干净
  - 残留目录（`app/plugins/<插件>`）
  - 插件数据
  - 插件配置
  - 模块缓存
  - 文件夹配置中的残留项
- **手动控制**：打开插件页面即自动扫描，点「一键清理残留」才执行清理
- **定时扫描通知**：可选定时扫描，发现残留只发通知，**绝不自动清理**
- **安全保护**：插件自身与「排除列表」中的插件始终不会被清理

## 使用

1. 安装插件后打开「插件残留清理」页面，即可看到当前残留情况
2. 点「一键清理残留」清掉全部卸载残留（执行后页面自动刷新结果）
3. 需要定期体检时：插件设置中开启「定时扫描」，配置扫描时间

## 清理范围说明

只清理**已卸载**插件留下的残留；仍在运行/已安装的插件即使被扫描到，也仅展示提示，不会进入清理范围。

## 命令与 API

- 命令：`/pluginresidueclean`（手动扫描并汇报）
- API：
  - `POST /api/v1/plugin/PluginResidueClean/scan` 扫描
  - `POST /api/v1/plugin/PluginResidueClean/clean` 一键清理
