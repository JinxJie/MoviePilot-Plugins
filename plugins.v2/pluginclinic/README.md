# 插件诊所

扫描并清理 MoviePilot 中**无法加载的插件**与**卸载残留**，一键清理干净，让重新安装一路顺畅。

适用于 [MoviePilot](https://github.com/jxxghp/MoviePilot)。

## ✨ 功能

- 🔍 **打开插件页面自动扫描**：无需任何配置，点开即体检
- ❌ 定位**无法加载的插件**：缺依赖 / 代码错误 / 目录缺失，并显示具体异常信息
- 🗑️ 定位**卸载残留**：残留目录、插件数据（PluginData）、插件配置（SystemConfig）、模块缓存
- ✅ **手动勾选清理**：自己判断、自己选择，清理项留痕可回溯
- 🧹 **一键清理**：清掉全部异常与残留插件
- 📋 **清理记录**：最近 20 条记录展示在插件页面
- 📅 **可选定时扫描**：发现问题只发送通知，**绝不自动清理**
- 🛡️ **安全护栏**：插件诊所自身与「排除列表」中的插件永远不会被清理

## 📝 使用说明

### 1. 扫描

安装并打开插件页面，**扫描自动完成**。扫描结果按状态分类：

| 状态 | 含义 | 建议 |
|------|------|------|
| ✅ 正常 | 插件运行正常 | 无需处理 |
| ❌ 加载失败 | 已安装但导入报错（缺依赖/代码错误） | **清理后重装** |
| 🕳️ 记录残留 | 已安装记录存在但目录已删 | **清理**（重装被卡的元凶） |
| 🗑️ 目录残留 | 已卸载但目录还在 | 按需清理 |
| 💾 数据残留 | 已卸载但数据/配置/模块缓存还在 | 按需清理 |

### 2. 清理

- **清理所选**：在「扫描结果」中确认要清理的插件后执行（当前版本通过 API/命令触发）
- **一键清理**：清掉全部异常与残留插件
- 命令：`/pluginclinic`（扫描并通知结果）
- API：
  ```bash
  # 扫描
  curl -X POST http://<MP地址>:3000/api/v1/plugin/pluginclinic/scan
  # 清理指定插件
  curl -X POST http://<MP地址>:3000/api/v1/plugin/pluginclinic/clean \
    -H "Content-Type: application/json" \
    -d '{"pids": ["BadPlugin"], "scope": "selected"}'
  # 一键清理全部异常与残留
  curl -X POST http://<MP地址>:3000/api/v1/plugin/pluginclinic/clean \
    -H "Content-Type: application/json" \
    -d '{"scope": "all"}'
  # 清理记录
  curl http://<MP地址>:3000/api/v1/plugin/pluginclinic/records
  ```

### 3. 配置

| 配置 | 说明 |
|------|------|
| 启用插件 | 开启后可响应命令与 API |
| 定时扫描 | 开启后按 Cron 定时扫描，只通知，不清理 |
| 扫描时间 | 默认每天 02:00，仅定时扫描开启时生效 |
| 发送通知 | 定时扫描发现问题、手动扫描/清理结果的通知总开关 |
| 排除插件 ID | 逗号分隔，这些插件不会被清理（插件诊所自身始终自动排除） |

> 定时扫描只负责发现问题和告警，**不会执行任何清理**。清理必须由你在插件页面确认后手动执行。

## ⚠️ 注意事项

- **清理为不可逆操作**：会删除插件目录、数据、配置，清理前请确认
- 插件诊所不会清理：自身、排除列表中的插件、状态正常的插件（一键清理仅针对异常与残留）
- 清理后建议重新扫描确认；如需重装插件，直接到插件市场安装即可

## 🛠️ 常见问题

| 问题 | 说明 |
|------|------|
| 扫描结果为空 | 说明环境干净，没有异常与残留 |
| 页面按钮无反应 | 清理操作可通过上方 API/命令触发 |
| 想保护某个插件 | 加入「排除插件 ID」配置 |
| 清理后插件还在 | 检查是否在排除列表，或插件在其他仓库目录 |
