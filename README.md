## 使用方法

在 MoviePilot **设置 → 插件 → 插件市场设置** 中添加本仓库地址：

```text
https://github.com/JinxJie/MoviePilot-Plugins
```

然后在插件市场中安装对应插件即可，后续新增插件也会继续沿用本仓库。

## HHCLUB 自动抽奖

### 功能
- 🎰 自动抽奖
- 💰 余额追踪与结束前校准
- 🏆 大奖即时通知（VIP / 邀请 / 大额憨豆 / 自定义关键词）
- 📫 站内信自动清理
- ⏰ Cron 定时运行
- 🛑 手动停止当前抽奖
- ♻️ 最新保存接管运行
- 📊 今日 / 历史汇总
- 🎁 奖品统计与命中详情

### 配置
1. 安装插件后进入配置页面
2. 填入 HHCLUB Cookie（从浏览器 F12 复制）
3. 按需设置 Cron 表达式（默认 `5 0 * * *`，每天 0:05）
4. 保存后即可运行或等待定时执行

### 通知
- 抽奖命中：立即推送大奖通知
- 抽奖结束：推送结束结果、奖品统计、余额与盈亏
- 抽奖汇总：推送今日 / 历史汇总和奖品统计
- 异常停止：推送异常原因
