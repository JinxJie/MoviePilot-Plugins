# MoviePilot-Plugins

个人 MoviePilot 第三方插件仓库。

## 插件列表

| 插件 | 版本 | 说明 |
|------|------|------|
| [HHCLUB 自动抽奖](plugins/hhlottery/) | v1.0.0 | HHCLUB 自动抽奖增强版，支持大奖即时通知、站内信自动清理、Cron 定时运行 |

## 使用方法

在 MoviePilot **设置 → 插件 → 第三方插件源** 中添加本仓库地址：

```
https://raw.githubusercontent.com/JinxJie/MoviePilot-Plugins/main/package.json
```

## HHCLUB 自动抽奖

### 功能
- 🎰 自动抽奖（默认 8 秒间隔，自适应限流）
- 💰 余额追踪（每 20 抽服务端校准）
- 🏆 大奖即时通知（VIP/邀请/大额憨豆/自定义关键词）
- 📫 站内信自动清理（幸运大转盘通知）
- ⏰ Cron 定时运行（默认每天 0:05）
- 🛑 自动止损（余额不足/连续异常/大奖命中）

### 配置
1. 安装插件后进入配置页面
2. 填入 hhanclub Cookie（从浏览器 F12 复制）
3. 设置 Cron 表达式（默认 `5 0 * * *`，每天 0:05）
4. 保存即可自动运行

### 通知
- 中大奖：立即推送（含奖品名称、当前余额）
- 抽奖结束：推送明细（总次数、消耗、中奖统计、余额）
- 异常停止：推送原因
