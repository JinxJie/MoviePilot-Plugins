# MoviePilot-Plugins

JinxJie 的 [MoviePilot](https://github.com/jxxghp/MoviePilot) 第三方插件库。

本库 fork 自官方 [jxxghp/MoviePilot-Plugins](https://github.com/jxxghp/MoviePilot-Plugins)，仅保留本人开发的插件，便于后续持续新增。

## 插件列表

| 插件 | 目录 | 版本 | 说明 |
|------|------|------|------|
| HHCLUB 自动抽奖（V2） | [`plugins.v2/hhlottery`](plugins.v2/hhlottery) | 1.0.8 | 定时自动抽奖、大奖通知、盈亏统计、站内信清理 |
| NodeSeek 自动签到（V3） | [`plugins.v3/nodeseek`](plugins.v3/nodeseek) | 3.0.1 | 每日签到、鸡腿收益统计、签到记录与消息通知 |
| 癫影自动签到（V3） | [`plugins.v3/dian115sign`](plugins.v3/dian115sign) | 3.0.0 | 普通签与运气签、可选签到后最大抽奖、实时积分 |
| 癫影娱乐（V3） | [`plugins.v3/dian115wheel`](plugins.v3/dian115wheel) | 3.1.2 | 转盘、大富翁独立游玩，过程日志、积分护栏及结果记录 |
| 栖影自动签到（V3） | [`plugins.v3/hdhavensign`](plugins.v3/hdhavensign) | 3.0.3 | 只读账户概览、签到记录及结果通知；支持可选 Browserless |

## 📖 使用说明

**1. 添加仓库地址**

在 MoviePilot 「插件管理」中添加仓库地址：
```
https://github.com/JinxJie/MoviePilot-Plugins
```

**2. 安装与配置**

- 在 MoviePilot 中安装插件。
- 根据插件说明配置相关参数。
- 启用插件并设置定时任务（如需要）。

**v3.0.1 · 签到自动化 · NodeSeek 论坛**

**功能：**
NodeSeek 论坛每日自动签到，使用 curl_cffi 模拟 Chrome 浏览器指纹绕过 Cloudflare 拦截，支持鸡腿收益统计、签到历史记录和消息通知。

**标签：**
论坛签到、每日定时、自动化、数据统计、消息通知

**特点：**
- 📅 支持 Cron 定时自动签到（默认每天 00:30，可自定义）
- 🛡️ 使用 curl_cffi 模拟 Chrome 指纹，绕过 Cloudflare 拦截
- 🍗 鸡腿收益统计：累计签到天数、累计鸡腿、本月签到
- 📋 签到历史记录（最近 12 条）
- 🔔 通知：签到成功 / 今日已签到 / 签到失败 / Cookie 失效
- ⌨️ 命令 `/nodeseek` 与 API `/nodeseek/sign` 手动签到
- 🌐 V3 原生浏览器上下文可作为 Cookie 无效时的回退路径；支持系统代理。

4. V3 版本优先使用 `curl_cffi`，缺少依赖时会回退 requests 并提示；备用登录需在设置中配置账号与兼容的验证码服务。

<summary>3. 📅 癫影自动签到（Dian115Sign · V3）</summary>

**v3.0.0 · 签到与可选转盘 · 癫影（dian115.com）**

**功能：**
癫影每日自动签到；可选在签到成功或今日已签到后，按站点剩余额度逐次运行付费转盘。首页展示签到状态、转盘状态与只读实时积分，通知合并展示签到和抽奖结果。使用 curl_cffi 模拟 Chrome 指纹，并以 ECDSA P-256 完成请求签名。

**标签：**
每日签到、运气签、自动化、数据统计、消息通知

**特点：**
- 📅 支持 Cron 定时自动签到（默认每天 09:30，可自定义）
- 🎲 运气签模式开关：开 = 运气签（49% 得 3~10 倍 / 10% 平手 / 20% 空签 / 21% 倒霉扣分）；关 = 普通签固定积分
- 🛡️ 使用 curl_cffi Chrome 110+ 指纹通过站点 WAF 防护
- 🔐 ECDSA P-256 动态密钥 + browser-session 注册 + portal-browser-request/v1 请求签名
- 👤 插件页面展示账号信息：昵称、邮箱、当前积分、连续签到天数
- 🧧 获得积分、倍率档位（大奖/平手/空签/倒霉）、余额与连签统计
- 📋 本月签到记录表（最近 30 条）
- 🔁 失败自动重试（可配置次数）
- 🎡 「签到后最大抽奖」默认关闭；开启后按站点当日剩余次数逐次抽奖，抽后至少保留 5 积分；抽奖请求结果不明时停止，当日再次运行也不自动重抽。
- 💰 首页显示只读实时积分与今日转盘状态；查询失败明确显示「获取失败」，本地仅统计已确认结果。
- 🔔 签到和抽奖合并通知，奖品每行两个；转盘关闭时维持原签到通知。
- 🚀 支持立即运行一次用于调试 Token 与网络；开启转盘时也会消耗积分。

**使用说明：**
1. 在 MoviePilot 插件管理中添加本仓库地址，安装原生 V3 版本 `plugins.v3/dian115sign`；升级前请备份原配置和签到记录，安装后检查 Token、Cron、代理及「签到后最大抽奖」开关（默认关闭）。
2. 浏览器登录 m.dian115.com 后按 F12 → Application → Cookies → 复制 `__Host-portal_token` 的值，填入插件配置。
3. 配置签到时间与签到模式（默认每天 09:30，普通签）。
4. 可开启「立即运行一次」测试；**若同时开启「签到后最大抽奖」，手动运行也将消耗积分**。请先关闭独立转盘插件的定时任务，避免双重执行。需确保环境已安装 `curl_cffi` 与 `cryptography`；转盘记录与独立插件历史不自动合并。

**免责声明：**
本插件签到使用站点现有接口；开启转盘后会发起**消耗积分**的抽奖请求，结果随机，站点规则、接口及防护策略变更可能造成账号风险。请自行评估后启用；开发者不保证中奖或承担使用后果。

**更新说明：**
- v3.0.0：新增 V3 原生实现，兼容字典或对象型系统代理；保留签到与默认关闭的签到后最大抽奖，修复签到签名格式并加强付费请求保护。

<summary>4. 🎲 癫影娱乐（Dian115Wheel · V3）</summary>

**v3.1.2 · 站点自动化 · 癫影（m.dian115.com）**

**功能：**
通过癫影站点接口分别启用幸运转盘或幸运大富翁；两个都开启时先运行转盘、再运行大富翁，支持手动或 Cron 定时游玩。执行中输出开始、预检、冷却和单次结果日志；首页实时显示站点积分，游玩记录以绿/红区分正负奖励，记录积分消耗和奖励；通知展示各玩法结束时积分和每行两个的结果。两种玩法均可能消耗积分。

**标签：**
幸运转盘、大富翁、积分、定时任务、消息通知

**特点：**
- 默认关闭定时任务；幸运转盘开关默认开启、大富翁开关默认关闭。两者都开启时先转盘再大富翁；两个都关闭时不进行消费。转盘与大富翁各有独立的「自定义次数」（每轮默认各 1 次）、「最大次数」开关和最低保留积分；最大次数按各自当日剩余额度执行，不影响另一玩法的设置。
- 每次游玩前读取对应玩法的站点每日限额、次数、单次成本和余额；达到限制即停止该玩法。转盘请求结果不明或预检异常时不继续运行大富翁；额度用尽或余额不足时可继续检查大富翁自己的额度和余额。两种玩法共享消费冷却记录，消费尝试后下一轮预检前等待 15–25 秒随机间隔；单实例重启后仍读取该记录，但不保证多实例并发互斥或避免站点限流。
- 消费性 POST 失败不自动重试；大富翁发送前保存待核对标记。仅服务端明确返回限流拒绝、站点已用次数与请求前一致且积分可读时，下次运行才自动恢复；超时、结果不明或旧标记保持拦截，避免重复消费与账目缺失。
- 支持系统代理（默认开启）及自定义代理，采用 browser-session 与 ECDSA 请求签名。
- 本地记录和通知；配置页「立即运行一次」以及已鉴权的 POST `/spin` 可手动执行。
- 首页只读查询当前站点积分；通知在游玩后重新查询积分，失败时显示「获取失败」，结果每行两个；若已遇站点限流则不再查询积分。

**使用说明：**
1. 从癫影浏览器 Cookie 获取 `__Host-portal_token`，填入插件配置；不与签到插件共享登录状态。
2. 通过「运行幸运大转盘」和「运行幸运大富翁」分别启停：旧配置仅运行转盘；两个都打开时按转盘→大富翁执行。每种玩法在其开关下分别设置自定义次数、最大次数和最低保留积分（默认每轮各 1 次、各保留 5 积分）；最大次数开启时仅忽略该玩法的自定义次数，按该玩法今日剩余额度执行。定时执行需主动启用，默认每天 10:00，手动运行同样可能消耗积分。遇到 `rate_limited` 时本轮停止；仅明确拒绝且站点次数未变时下轮可自动恢复。对旧版或结果不明的待核对标记保持拦截，请先人工核对站点次数、积分及记录，不要反复点击立即运行。
3. V3 插件依赖 `curl_cffi` 与 `cryptography`；Token 过期后须自行更新。历史上已用真实账号验证转盘单次抽奖（站点扣 5 积分、奖励 3 积分）；用户运行日志显示大富翁成功游玩 1 次后收到站点 `rate_limited`，新版冷却策略仅经离线模拟测试，尚未完成站点实测验收。

**免责声明：**
抽奖存在积分消耗和随机结果；站点规则、接口及成本可能变动。请自行评估，插件不保证中奖，也不代替站点风控规则。

**更新说明：**
- v3.1.2：新增执行过程日志、首页记录正负积分着色和设置项间距；大富翁仅在明确限流拒绝且站点次数未变时自动恢复，未知结果继续阻断；加强转盘和大富翁重复结果的记录持久化校验。
- v3.1.1：转盘和大富翁共享持久化消费冷却记录，每次消费尝试后随机等待 15–25 秒再预检；限流后停止并跳过通知的积分查询。
- v3.1.0：更名癫影娱乐并启用新图标；新增幸运大富翁独立开关，双开时先转盘后大富翁；加入积分、额度与消费结果待核对保护。
- v3.0.2：兼容 MoviePilot V3 字典形式的系统代理，修复转盘请求未使用系统代理的问题。
- v3.0.1：首页实时显示站点积分；抽奖通知展示结束时积分，奖品每行两个，并保留提前结束原因。
- v3.0.0：V3 原生插件版本统一从 3.0.0 起；支持定时和手动转盘、积分护栏、结果记录与通知。
- v1.0.0：首版 V3 原生实现，支持定时和手动转盘、积分护栏、结果记录与通知。

<summary>5. 🌙 栖影自动签到（HDHavenSign · V3）</summary>

**v3.0.3 · 签到自动化 · 栖影（hdhaven.com）**

**功能：**
使用浏览器登录取得的会话执行每日签到；支持 Cron 定时、保存后运行一次、只读站点签到状态核对、系统代理、可选 Browserless 备用模式与分行结果通知。首页只读查询账户信息，并展示今日状态与最近 30 条本地签到记录。站点确认已签到则跳过，明确未签到才提交签到请求；状态不明时不提交。

**标签：**
每日签到、自动化、定时任务、消息通知

**特点：**
- 📅 定时任务默认关闭，Cron 默认每天 09:30；可保存后运行一次。
- 🔐 每次先只读检查会话和站点 `checkin_today` 状态；插件不执行登录或人机验证。
- 🛡️ 单实例内遇到未知响应或超时会保留待核对标记；再次运行仍先查站点，明确未签到才提交。不同实例并行运行不提供互斥保证，请勿同时部署多个实例。
- 🌐 支持系统代理（默认开启）与自定义代理；成功后显示积分与连续签到天数。
- 🧭 Browserless 备用模式默认关闭，设置项独立分组；开启后站点预检和签到改走远程浏览器，不自动回退或重发请求。
- 📊 首页账户信息仅通过只读请求获取；本地签到记录按日期去重，最多保留最近 30 条，旧版单条结果不冒充完整历史。
- 🔔 成功、已签到与结果待核对分别通知；站点未提供的数值标为“未提供”，不推算奖励。

**使用说明：**
1. 在自己的浏览器登录栖影并完成人机验证；在 MoviePilot 插件设置中填写新的有效登录会话 Cookie，不要发到聊天中。
2. 首次安装定时任务关闭；确认会话有效后，可手动运行一次或开启定时签到。会话失效需自行更新。
3. 不需要 Browserless 时保持开关关闭，原有签到路径不变。备用时，在设置页的「Browserless 备用模式」区域开启开关，填写可信服务的完整 HTTPS `/function?token=...` 地址；保存后请求才会改走远程浏览器。请勿在群聊、日志中公开含令牌的地址或 Cookie。
4. 插件的系统/自定义代理只影响它连接 Browserless 服务，不改变远程浏览器访问栖影的出口 IP。Browserless 不负责登录或自动处理人机验证；先自行验证服务连接和站点读取，再启用定时任务。请求结果不明时不自动重发签到，需先核对站点记录。
5. 原有 3.0.1 签到已由用户在站点验证；Browserless 模式仅通过无凭据模拟响应的离线测试，尚未在真实 Browserless 服务或 MoviePilot 宿主验收。

**免责声明：**
