# 栖影自动签到（MoviePilot V3）

V3 原生插件 v3.0.0：从用户已登录浏览器获取会话 Cookie，在 MoviePilot 插件配置中填写；默认关闭定时任务，支持手动执行、Cron 定时签到、系统代理与结果通知。先通过 `/api/auth/me` 只读预检会话，再执行不带请求体的 `POST /api/account/checkin`（依据用户浏览器 Network 中一次成功记录）。单实例内签到结果未知时留下当日待核对标记，不自动重试；不同实例并行运行不保证互斥，请勿同时部署多个实例。

**验收边界：** 已通过无凭据模拟响应的离线测试；尚未用真实会话在 MoviePilot 宿主验证只读预检、签到及已签到响应。登录环节需要人工在浏览器完成人机验证，插件不提供自动登录或验证码绕过。站点接口或保护机制变化可能导致失败；请以站点记录为准。

**安全提醒：** 此前会话 Cookie 曾发到群聊，建议在站点撤销旧会话、重新登录；新 Cookie 仅保存在自己的 MoviePilot 配置，不发送到聊天。
